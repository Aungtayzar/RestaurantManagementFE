# UI Guidelines

## Layout

- Desktop and tablet first.
- POS must work comfortably on tablet.
- Navigation changes based on role.

## Forms

- Labels above inputs.
- Validation errors displayed near fields.
- Disable submit while saving.
- Show success/error toast after mutations.

## Loading

Every API-driven page should handle:

- loading
- empty
- error
- success

## Tables

Use consistent:

- pagination
- sorting
- filtering
- empty states
- loading states

## Statuses

Order statuses:

Pending
Preparing
Ready
Completed

Use the same visual treatment everywhere.

## Money

Display monetary values consistently.
Never calculate authoritative totals in the frontend.
